# Piloto Akoma Ntoso

`NOR-004-articulo-1.xml` es una exportación técnica y reproducible del artículo 1 de la Ley 6/2014. Su finalidad es probar la estructura, los identificadores FRBR y la trazabilidad ELI antes de valorar una conversión más amplia.

## Alcance y garantías

- Incluye únicamente el artículo 1; no representa el texto completo ni una consolidación jurídica.
- Se genera desde `11_calidad/generar_interoperabilidad.py`; no se edita manualmente.
- El contenido se contrasta con la copia local de consulta y enlaza el [texto consolidado oficial del BOE](https://www.boe.es/eli/es-cn/l/2014/07/25/6/con).
- Se ha validado localmente contra el XSD oficial de [Akoma Ntoso 3.0 / OASIS LegalDocML 1.0](https://docs.oasis-open.org/legaldocml/akn-core/v1.0/os/part2-specs/schemas/akomantoso30.xsd).
- No sustituye al BOE, no es una publicación oficial y no debe utilizarse como fuente jurídica autónoma.

La ampliación a más artículos requiere segmentación estructural, revisión humana de cada bloque y validación XSD; no debe inferirse automáticamente a partir de saltos de línea del texto plano.
